  Пошаговое руководство по разрешению конфликтов слияния в Git: маркеры конфликта, ручное редактирование, git mergetool, отмена слияния.
symptoms:
  - При выполнении git merge появляется сообщение CONFLICT
  - В файле видны маркеры <<<<<<<, =======, >>>>>>>
  - Git не может автоматически объединить изменения
causes:
  - Два разработчика изменили одну и ту же строку в разных ветках
  - Удаление файла, который был изменён в другой ветке
  - Переименование файла в одной ветке и изменение в другой
steps:
  - title: Найдите конфликтные файлы
    body: >-
      Выполните git status — конфликтные файлы будут помечены как «both modified». Откройте каждый файл и найдите маркеры <<<<<<< (начало конфликта), ======= (середина), >>>>>>> (конец).
    command: git status
    image: null
  - title: Отредактируйте файл вручную
    body: >-
      Откройте конфликтный файл в редакторе. Между маркерами будут две версии кода. Выберите нужную версию (или объедините обе), удалите все маркеры <<<<<<<, =======, >>>>>>>. Сохраните файл.
    command: null
    image: null
  - title: Пометьте файл как разрешённый
    body: >-
      После редактирования файла выполните git add <имя_файла>. Это пометит файл как разрешённый конфликт. Для пометки всех файлов: git add .
    command: git add .
    image: null
  - title: Завершите слияние
    body: >-
      Выполните git commit для завершения слияния. Git автоматически создаст коммит слияния. Если используете rebase — выполните git rebase --continue.
    command: git commit -m "resolve merge conflict"
    image: null
  - title: Используйте git mergetool для удобства
    body: >-
      Для визуального разрешения конфликтов выполните git mergetool. Откроется графический редактор (meld, kdiff3, vimdiff), где вы увидите обе версии и результат. Это удобнее ручного редактирования.
    command: git mergetool
    image: null

При конфликте слияния в Git найдите конфликтные файлы через git status, отредактируйте их вручную (удалите маркеры), затем выполните git add и git commit. Для удобства используйте git mergetool с графическим редактором.
