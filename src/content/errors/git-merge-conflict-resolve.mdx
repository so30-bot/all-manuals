## Суть проблемы

Git merge conflict: как разрешить конфликт слияния нужно разбирать по фактическому месту сбоя, а не по общей формулировке ошибки. Сначала подтвердите, что проблема относится именно к Git merge conflict: совпадает действие, сообщение, версия компонента и момент появления симптома.

## Что уточнить перед исправлением

Проверьте runtime, package manager, зависимости, виртуальное окружение, путь модуля и команду сборки. Сохраните точный текст ошибки, последние изменения, версию продукта и короткий фрагмент журнала. Не удаляйте данные, профиль, volume, раздел или конфигурацию, пока лог не показывает, что причина именно в них.

## Проверка результата

После каждого изменения повторяйте тот же сценарий, на котором проявлялся сбой. Проблема считается решенной, если команда установки, теста или запуска завершается без исходной ошибки. Если появилась другая ошибка, зафиксируйте ее отдельно: это может быть следующий слой причины, а не возврат исходной проблемы.

## Когда останавливать правки

Остановитесь, если следующий шаг требует удаления данных, сброса профиля, переустановки системы, изменения прав без отката или работы с производственной конфигурацией. Сначала сделайте резервную копию и сохраните исходные параметры.
