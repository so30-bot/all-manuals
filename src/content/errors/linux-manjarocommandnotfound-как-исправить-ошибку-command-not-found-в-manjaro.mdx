Manjaro — это дружелюбный и доступный дистрибутив Linux, основанный на Arch Linux, известный своей простотой настройки и использования. Он использует модель 'rolling release', что означает постоянные обновления системы без необходимости переустановки. Управление пакетами в Manjaro осуществляется с помощью Pacman (через командную строку) и предустановленного графического менеджера Pamac. Также доступен Arch User Repository (AUR), который расширяет количество доступного программного обеспечения.
