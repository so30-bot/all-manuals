symptoms:
  - Письма не приходят в входящие Outlook
  - Задержка доставки писем
  - Ошибка при отправке или получении почты
causes:
  - Заполнено хранилище данных Outlook (.pst)
  - Неправильные настройки сервера POP/IMAP
  - Правила или фильтры спама блокируют письма
steps:
  - title: Проверьте размер хранилища данных
    body: >-
      Откройте «Файл» → «Настройка учётной записи» → «Настройка учётных записей» → «Файлы данных». Если размер .pst-файла приближается к лимиту (обычно 50 ГБ), архивируйте старые письма или очистите корзину.
    command: null
    image: null
  - title: Отключите правила фильтрации
    body: >-
      Перейдите в «Главная» → «Правила» → «Управление правилами и оповещениями». Временно отключите все правила, которые могут перемещать или удалять входящие письма. Проверьте папку «Нежелательная почта».
    command: null
    image: null
  - title: Проверьте настройки сервера
    body: >-
      Откройте «Файл» → «Настройка учётной записи» → дважды щёлкните по учётной записи. Убедитесь, что настройки POP/IMAP, SMTP и порты правильные. Для Microsoft 365 используйте autodiscover.
    command: null
    image: null
  - title: Создайте новый профиль Outlook
    body: >-
      Закройте Outlook. Откройте «Панель управления» → «Почта» → «Профили» → «Добавить». Создайте новый профиль, настройте учётную запись и выберите его по умолчанию при запуске.
    command: null
    image: null
  - title: Запустите средство устранения неполадок
    body: >-
      Скачайте и запустите Microsoft Support and Recovery Assistant. Выберите «Outlook» → «Письма не приходят» и следуйте инструкциям. Средство автоматически проверит настройки и исправит типичные проблемы.

Если Outlook не получает письма, начните с проверки размера хранилища данных и отключения правил фильтрации. Если проблема сохраняется — создайте новый профиль Outlook или запустите средство устранения неполадок Microsoft.
