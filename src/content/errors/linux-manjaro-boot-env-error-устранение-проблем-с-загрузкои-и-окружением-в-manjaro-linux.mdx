При работе с Manjaro Linux пользователи могут столкнуться с двумя типами проблем: сбоями при инициализации графического экрана загрузки и некорректным определением путей для установленного ПО (например, .NET SDK) при запуске программ через ярлыки в меню. В данной статье мы разобрали, как устранить эти неприятности. Основная причина проблем с окружением заключается в том, что приложения, запущенные через графический интерфейс, не всегда наследуют переменные среды из .bashrc, поэтому использование ~/.profile является более надежным способом для Linux-систем. Для проблем с загрузкой важно соблюдать очередность инициализации служб, чтобы избежать конфликтов доступа к видеопамяти (/dev/fb0).
