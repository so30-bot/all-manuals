Когда вы вводите команду в терминале Ubuntu и получаете сообщение "command not found", это означает, что система не может найти исполняемый файл для этой команды. Чаще всего это происходит по двум основным причинам: либо команда действительно не установлена, либо система не знает, где ее искать из-за неправильно настроенной переменной окружения PATH.

**Шаг 1: Проверка и восстановление переменной PATH**

Переменная PATH содержит список директорий, в которых оболочка (например, bash) ищет исполняемые файлы. Если эта переменная настроена некорректно, команды не будут найдены.

1.  Откройте терминал.
2.  Введите команду `echo $PATH`, чтобы увидеть текущее содержимое переменной PATH.
3.  Чтобы временно исправить PATH, введите команду `export PATH=/bin:/usr/bin:/usr/local/bin:/usr/local/sbin`. Эта команда устанавливает стандартный набор путей для поиска команд. Если после этого команды начали работать, проблема именно в вашей переменной PATH.

**Шаг 2: Проверка установки команды**

Если команда, которую вы пытаетесь выполнить, не является системной утилитой, возможно, она просто не установлена.

1.  Попробуйте установить команду с помощью пакетного менеджера APT. Например, если вы искали команду `cpufetch`, выполните:
    ```bash
    sudo apt update
    sudo apt install cpufetch
    ```
2.  Ubuntu также активно использует формат пакетов Snap. Если команда доступна как Snap-пакет, система может предложить установить ее через `snap install`.

**Шаг 3: Проверка конфигурационного файла .profile**

Иногда ошибки в файле `.profile`, который находится в вашем домашнем каталоге (`~/.profile`), могут привести к некорректной работе переменной PATH или другим проблемам.

1.  Сделайте резервную копию файла `.profile`:
    ```bash
    mv ~/.profile ~/.profile.bak
    ```
2.  Перезапустите терминал или выйдите из системы и войдите снова.
3.  Попробуйте выполнить команды. Если ошибка исчезла, значит, проблема была в файле `.profile`. Вы можете восстановить его из `.profile.bak` или отредактировать `.profile.bak`, чтобы исправить ошибку, а затем снова переименовать его в `.profile`.
