Когда вы работаете в терминале Ubuntu и вводите команду, которая не распознается системой, вы можете столкнуться с сообщением "command not found". Это означает, что оболочка (например, Bash) не смогла найти исполняемый файл для введенной команды в директориях, указанных в переменной окружения PATH.

Существует несколько причин возникновения этой ошибки и способов ее устранения.

### Проверка и настройка переменной окружения PATH

Переменная PATH — это список директорий, в которых система ищет исполняемые файлы. Если команда, которую вы пытаетесь запустить, находится в директории, не включенной в PATH, вы получите ошибку.

1.  **Проверьте текущий PATH:**
    ```bash
    echo $PATH
    ```
    Вы должны увидеть список директорий, разделенных двоеточиями, например: `/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin`.

2.  **Временно добавьте необходимые пути:**
    Если нужных директорий нет, вы можете временно добавить их:
    ```bash
    export PATH=/bin:/usr/bin:/usr/local/bin:/usr/local/sbin:$PATH
    ```
    После этого попробуйте выполнить команду снова.

3.  **Сделайте изменения постоянными:**
    Чтобы изменения стали постоянными, отредактируйте файл `~/.bashrc` (или `~/.profile`) в вашем домашнем каталоге и добавьте туда строку с `export PATH=...`.
    ```bash
    nano ~/.bashrc
    ```
    Добавьте строку в конец файла, сохраните и закройте редактор (Ctrl+X, Y, Enter).

### Использование встроенной помощи `command-not-found`

Ubuntu имеет механизм, который подсказывает, как установить недостающие команды. Обычно он работает автоматически, но вы можете вызвать его и вручную для получения информации.

1.  **Вызовите обработчик команды:**
    Если вы ввели команду, например `cpufetch`, и получили ошибку, попробуйте выполнить:
    ```bash
    /usr/lib/command-not-found cpufetch
    ```
    В ответ система предложит установить пакет, содержащий эту команду, например:
    ```
    Command 'cpufetch' not found, but can be installed with:
    sudo snap install cpufetch  # version 1.04, or
    sudo apt  install cpufetch  # version 1.01+git20211208+40b13bc-2
    See 'snap info cpufetch' for additional versions.
    ```

### Проверка конфигурационных файлов

Ошибки в конфигурационных файлах оболочки (например, `~/.profile` или `~/.bashrc`) могут привести к некорректной работе команды PATH и, как следствие, к ошибке "command not found".

1.  **Создайте резервную копию:**
    ```bash
    mv ~/.profile ~/.profile_backup
    ```

2.  **Перезапустите терминал или перелогиньтесь.**

3.  **Проверьте работу команд:**
    Если команды теперь работают, значит, проблема была в файле `~/.profile`. Восстановите его из резервной копии:
    ```bash
    mv ~/.profile_backup ~/.profile
    ```
    Затем откройте файл `~/.profile` в текстовом редакторе (например, `nano ~/.profile`) и внимательно проверьте его содержимое на наличие ошибок, особенно в секциях, касающихся переменных окружения.
