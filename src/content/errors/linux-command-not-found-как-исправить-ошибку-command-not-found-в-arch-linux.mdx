Ошибка «command not found» в Manjaro Linux чаще всего означает, что система не может найти исполняемый файл запрашиваемой программы. В дистрибутивах на базе Arch, таких как Manjaro, управление ПО осуществляется через менеджер пакетов pacman или его графическую оболочку Pamac. 

Сначала проверьте, установлена ли программа, выполнив поиск через Pamac. Если программа найдена, установите её стандартными средствами. Если же программа установлена, но всё равно не запускается, возможно, путь к её исполняемому файлу не прописан в системной переменной PATH или требуется перезапуск сессии терминала для обновления окружения.
