Ошибка «command not found» в Arch Linux означает, что интерпретатор Bash или Zsh не может найти исполняемый файл с указанным именем в системных директориях. Чаще всего это происходит из-за того, что программа ещё не установлена. Поскольку Arch Linux — минималистичный дистрибутив, многие утилиты не предустановлены по умолчанию. Сначала проверьте, есть ли пакет в официальных репозиториях с помощью 'pacman -F'. Если пакет найден, установите его через 'sudo pacman -S'. Если же вы уверены, что программа установлена, проверьте переменную PATH, чтобы убедиться, что система «видит» директорию, где лежит исполняемый файл.
