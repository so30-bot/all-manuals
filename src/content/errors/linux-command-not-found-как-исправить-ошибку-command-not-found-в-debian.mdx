      команды. Убедитесь, что вы используете строчные буквы, так как Linux
      чувствителен к регистру.
    command: null

    body: >-
      Если команда введена верно, возможно, программа просто не установлена.
      Используйте менеджер пакетов APT для поиска и установки нужного ПО.
      Сначала обновите список репозиториев, затем установите пакет.
    command: sudo apt update && sudo apt install имя_пакета
    image: null
  - title: Проверьте пути к исполняемым файлам (PATH)
    body: >-
      Если программа установлена, но система её не «видит», значит путь к ней не
      добавлен в переменную PATH. Вы можете проверить текущее значение
      переменной, введя следующую команду. Если нужной директории там нет,
      программу придется запускать, указывая полный путь (например,
      /usr/local/bin/программа).
    command: echo $PATH

Ошибка «command not found» в Debian означает, что оболочка Bash не может найти исполняемый файл, соответствующий введенной вами команде. Это может произойти, если программа не установлена, путь к ней не прописан в системных переменных или вы допустили опечатку. Следуйте приведенным шагам для диагностики и решения проблемы.
