Ошибка «command not found» в Debian означает, что оболочка Bash не может найти исполняемый файл с указанным именем в системных директориях. Это происходит либо из-за того, что программа не установлена, либо путь к ней не прописан в переменной окружения PATH. Следуйте приведенным выше шагам, чтобы найти и установить необходимое программное обеспечение.
