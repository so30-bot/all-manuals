description: >-
  Подробное руководство по устранению критической ошибки 0xc000021a (синий экран

symptoms:
  - >-
    Компьютер не загружается и отображает синий экран смерти (BSOD) с кодом
    ошибки 0xc000021a.
  - >-
    Система может уходить в циклическую перезагрузку или зависать на экране
    «Подготовка автоматического восстановления» без прогресса.
  - Невозможно войти в безопасный режим операционной системы.
causes:
  - >-
    Повреждение или удаление критически важных системных файлов Windows, таких
    как csrss.exe или winlogon.exe.
  - >-
    Неудачные обновления Windows или установка сторонних программ, которые
    влияют на файлы ядра системы или драйверы.
  - >-
    Проблемы с драйверами устройств, включая конфликты или некорректную цифровую
    подпись.
  - >-
    Некорректное клонирование жесткого диска (HDD) или твердотельного накопителя
    (SSD).
  - >-
    Сбои в работе аппаратного обеспечения, например, неисправная оперативная
    память, проблемы с питанием или перегрев компонентов.
steps:
  - title: Вход в среду восстановления Windows (WinRE)
    body: >-
      Для устранения ошибки 0xc000021a необходимо получить доступ к среде
      восстановления Windows (WinRE), так как операционная система не может
      загрузиться в обычном режиме.


      1.  **Автоматический способ:** Несколько раз подряд перезагрузите
      компьютер во время загрузки Windows (например, при появлении логотипа
      Windows). Система должна автоматически обнаружить проблему и предложить
      запустить процедуру автоматического восстановления. На экране с
      предложением автовосстановления выберите «Дополнительные параметры».

      2.  **Принудительный способ:** Если автоматическое восстановление не
      запускается, дважды прервите загрузку компьютера на раннем этапе,
      удерживая кнопку питания, пока компьютер не выключится. После двух таких
      принудительных выключений система должна загрузиться в среду
      восстановления.

      3.  **С установочного носителя:** Если предыдущие способы не сработали,
      создайте загрузочный USB-накопитель или DVD-диск с установочным
      дистрибутивом Windows 10/11. Загрузитесь с этого носителя (возможно,
      потребуется изменить порядок загрузки в BIOS/UEFI). В окне мастера
      установки выберите «Восстановление системы» вместо «Установить».

  - title: Отключение проверки цифровой подписи драйверов
    body: >-
      Если ошибка 0xc000021a появилась после установки новых драйверов или
      программ, содержащих их, проблема может быть связана с некорректной
      цифровой подписью драйверов.


      1.  В среде восстановления WinRE выберите «Поиск и устранение
      неисправностей».

      2.  Затем перейдите в «Дополнительные параметры» → «Параметры загрузки».

      3.  Нажмите кнопку «Перезагрузить».

      4.  После перезагрузки компьютера появится экран с дополнительными
      настройками загрузки. Нажмите клавишу F7, чтобы загрузить систему с
      отключенной проверкой цифровой подписи драйверов.

      5.  Если Windows успешно загрузится, немедленно удалите или откатите
      установленные/обновленные драйверы или деинсталлируйте программы, которые,
      предположительно, вызвали ошибку.

  - title: Восстановление системы или удаление обновлений
    body: >-
      Повреждение системных файлов или записей реестра, а также неудачные
      обновления, являются частыми причинами ошибки 0xc000021a. Попробуйте
      откатиться к предыдущему состоянию или удалить последние изменения.


      *   **Использование точки восстановления:**
          1.  В среде WinRE выберите «Поиск и устранение неисправностей» → «Дополнительные параметры» → «Восстановление системы».
          2.  Выберите целевую операционную систему (если потребуется).
          3.  Нажмите «Далее» и следуйте указаниям мастера, чтобы выбрать доступную точку восстановления, созданную до возникновения проблемы.
      *   **Удаление последних обновлений:**
          1.  В среде WinRE выберите «Поиск и устранение неисправностей» → «Дополнительные параметры» → «Удалить обновления».
          2.  Выберите тип обновления для удаления: «Удалить последнее исправление» для патчей или «Удалить последнее обновление компонентов» для отката к предыдущей сборке Windows.
          3.  Подтвердите действие и дождитесь завершения операции.

  - title: Проверка и восстановление целостности системных файлов
    body: >-
      Если предыдущие шаги не помогли, необходимо проверить и восстановить
      поврежденные системные файлы с помощью командной строки.


      1.  В WinRE выберите «Поиск и устранение неисправностей» → «Дополнительные
      параметры» → «Командная строка».

      2.  Определите буквы системных разделов, так как в среде восстановления
      они могут отличаться от обычных:
          *   Введите `diskpart` и нажмите Enter.
          *   Затем введите `list volume` и нажмите Enter, чтобы увидеть список всех дисковых томов. Определите, на каком томе установлена ваша Windows (обычно это самый большой раздел NTFS, можно поискать папку Windows с помощью `dir X:` где X - буква диска). Запомните буквы для загрузочного раздела и раздела с Windows.
          *   Введите `exit` и нажмите Enter, чтобы выйти из DiskPart.
      3.  Выполните команду для проверки и восстановления системных файлов:
          *   `sfc /scannow /offbootdir=C:\ /offwindir=D:\windows`
              *   Замените `C:` на букву вашего загрузочного раздела.
              *   Замените `D:\windows` на путь к папке Windows на вашем системном разделе.
      4.  Если утилита SFC не сможет решить проблему, попробуйте использовать
      инструмент DISM (только если вы загрузились с установочного носителя
      Windows):
          *   Снова определите буквы дисков (как в пункте 2).
          *   Введите: `DISM /Image:C:\ /Cleanup-Image /RestoreHealth /Source:D:\sources\install.wim /LimitAccess`
              *   Замените `C:` на букву диска, где установлена Windows.
              *   Замените `D:\sources\install.wim` на правильный путь к файлу `install.wim` на вашем установочном носителе. Если вместо `install.wim` у вас `install.esd`, используйте команду:
              *   `DISM /Image:C:\ /Cleanup-Image /RestoreHealth /Source:ESD:D:\sources\install.esd:1 /LimitAccess`
          *   После выполнения DISM, повторно запустите `sfc /scannow /offbootdir=C:\ /offwindir=C:\windows`.
      5.  Также можно запустить проверку диска на ошибки: `chkdsk C: /f /r`
      (замените `C:` на букву системного диска).
    command: >-
      diskpart

      list volume

      exit

      sfc /scannow /offbootdir=C:\ /offwindir=D:\windows

      DISM /Image:C:\ /Cleanup-Image /RestoreHealth
      /Source:D:\sources\install.wim /LimitAccess

      DISM /Image:C:\ /Cleanup-Image /RestoreHealth
      /Source:ESD:D:\sources\install.esd:1 /LimitAccess

      chkdsk C: /f /r

  - title: Перестроение данных конфигурации загрузки (BCD)
    body: >-
      Эта проблема часто возникает после клонирования дисков или при повреждении
      загрузочных записей.


      1.  Загрузитесь с установочного носителя Windows (как в Шаге 1) и выберите
      «Восстановление системы» → «Поиск и устранение неисправностей» →
      «Дополнительные параметры» → «Командная строка».

      2.  Используйте `diskpart` для определения и назначения буквы системному
      разделу EFI (обычно это скрытый FAT32 раздел):
          *   `diskpart`
          *   `list disk` (определите номер вашего основного диска)
          *   `select disk <номер вашего диска>`
          *   `list volume` (найдите EFI раздел, обычно FAT32, возможно, без буквы или с названием SYSTEM)
          *   `select volume <номер EFI раздела>`
          *   `assign letter=T:` (выберите любую свободную букву, например T)
          *   `exit`
      3.  **Внимание:** Следующий шаг (форматирование EFI раздела) может быть
      рискованным и потенциально привести к потере загрузочной информации, если
      выполнен неправильно. Используйте его с осторожностью. Если вы решили это
      сделать, выполните: `format T: /FS:FAT32`

      4.  Перестройте BCD, указав правильный путь к вашей папке Windows
      (например, `C:\windows`):
          *   `bcdboot C:\windows /s T: /f UEFI`
              *   Замените `C:` на фактическую букву диска, где установлена Windows.
              *   `T:` — это назначенная вами буква EFI раздела.
      5.  Дополнительно можно выполнить следующие команды для восстановления
      загрузочных записей (даже если предыдущая команда сработала):
          *   `bootrec /FixMbr`
          *   `bootrec /FixBoot`
          *   `bootrec /ScanOs`
          *   `bootrec /RebuildBcd`
      6.  Перезагрузите компьютер.
    command: |-
      diskpart
      list disk
      select disk <номер вашего диска>
      list volume
      select volume <номер EFI раздела>
      assign letter=T:
      exit
      format T: /FS:FAT32
      bcdboot C:\windows /s T: /f UEFI
      bootrec /FixMbr
      bootrec /FixBoot
      bootrec /ScanOs
      bootrec /RebuildBcd

  - title: Сброс Windows к исходному состоянию
    body: >-
      Если ни один из предложенных способов не помог устранить ошибку
      0xc000021a, последним решением будет сброс операционной системы Windows к
      заводским настройкам. Это позволит переустановить Windows, сохранив или
      удалив ваши личные файлы (в зависимости от выбранной опции).


      1.  В среде WinRE выберите «Поиск и устранение неисправностей» →
      «Восстановить компьютер в исходное состояние».

      2.  Следуйте инструкциям на экране, чтобы выбрать, сохранять ли личные
      файлы или удалить все. Имейте в виду, что все установленные программы и
      индивидуальные настройки будут удалены.

Ошибка 0xc000021a — это критическая системная ошибка (так называемый «синий экран смерти» или BSOD), которая не позволяет операционной системе Windows корректно загрузиться. Она часто возникает из-за повреждения системных файлов, проблем с драйверами или неудачных обновлений. В этой статье мы пошагово рассмотрим эффективные методы устранения этой проблемы, используя только проверенные решения из официальных и авторитетных источников. Для выполнения большинства шагов потребуется доступ к среде восстановления Windows (WinRE), которую можно запустить различными способами, описанными в первом шаге.
