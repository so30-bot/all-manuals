Столкнуться с ошибкой загрузки Ubuntu может каждый, но существуют проверенные способы решения этой проблемы. Чаще всего это связано с нехваткой места на диске, повреждением системных пакетов или проблемами с загрузчиком GRUB.

**1. Используем режим восстановления Ubuntu**

Первым делом, если система перестала загружаться, стоит попробовать зайти в режим восстановления. Для этого:

*   Перезагрузите компьютер.
*   Сразу после исчезновения логотипа BIOS/UEFI зажмите клавишу `Shift` (или `Esc`). Возможно, придется попробовать несколько раз, чтобы поймать нужный момент.
*   В появившемся меню GRUB выберите "Advanced options for Ubuntu".
*   Затем выберите один из пунктов "Recovery Mode" (Режим восстановления).

В меню восстановления есть несколько полезных опций:

*   **clean**: Эта опция пытается освободить место на диске. Иногда причиной проблем с загрузкой становится переполненный диск.
*   **dpkg**: Эта опция пытается исправить поврежденные пакеты программ, что также может вызывать сбои при загрузке.

Рекомендуется сначала попробовать "clean", а затем "dpkg". После выполнения каждой операции выберите "resume" для перезагрузки и проверки.

**2. Устанавливаем и запускаем Boot-Repair**

Если опции в режиме восстановления не помогли, следующим шагом будет использование утилиты Boot-Repair. Она предназначена для автоматического исправления многих проблем с загрузкой.

*   Создайте загрузочный USB-накопитель с Ubuntu (если у вас его нет).
*   Загрузитесь с этого Live USB.
*   Откройте терминал.
*   Добавьте репозиторий для Boot-Repair, выполнив команду:
    ```bash
    sudo add-apt-repository ppa:yannubuntu/boot-repair
    ```
*   Обновите список пакетов:
    ```bash
    sudo apt update
    ```
*   Установите Boot-Repair:
    ```bash
    sudo apt install boot-repair
    ```
*   Запустите утилиту:
    ```bash
    boot-repair
    ```
*   В открывшемся окне Boot-Repair выберите "Recommended repair" (Рекомендуемый ремонт). Эта опция исправляет наиболее частые проблемы с загрузкой и файловой системой.

**3. Анализируем системные логи**

Если даже Boot-Repair не смог решить проблему, необходимо вручную изучить системные журналы, чтобы найти причину.

*   Снова войдите в режим восстановления Ubuntu (как описано в первом пункте).
*   В меню восстановления выберите "root" (корневая оболочка).
*   Введите команду для просмотра логов загрузки:
    ```bash
    journalctl -xb
    ```
*   Внимательно изучите вывод. Ищите строки, помеченные как "error" или "failed", которые могут указывать на конкретный пакет или службу, вызывающую сбой.
*   Для просмотра последних системных сообщений, которые могут помочь выявить проблемы с драйверами или оборудованием, используйте команду:
    ```bash
    sudo dmesg | tail -50
    ```

Найдя информацию о проблемном пакете, вы можете попробовать исправить его с помощью `dpkg` в режиме восстановления или переустановить после загрузки с Live USB.
