Проблемы с загрузкой Ubuntu могут проявляться по-разному: от полного отсутствия изображения до зависания на этапе загрузки или сообщений об ошибках. К счастью, существует несколько проверенных способов решения этих проблем.

### Использование режима восстановления (Recovery Mode)

Если вам удается увидеть меню GRUB (обычно оно появляется, если нажать клавишу `Shift` или `Esc` сразу после исчезновения логотипа BIOS/UEFI), выберите "Advanced options for Ubuntu", а затем один из пунктов "Recovery Mode".

В меню режима восстановления есть несколько полезных опций:

1.  **clean**: Эта опция пытается освободить место на диске. Иногда недостаток свободного пространства может быть причиной проблем с загрузкой.
2.  **dpkg**: Эта опция пытается исправить ошибки в установленных пакетах программ, которые также могут вызывать сбои при загрузке.

Рекомендуется сначала попробовать "clean", а затем "dpkg". После выполнения каждой операции попробуйте перезагрузить систему, выбрав опцию "resume".

### Использование утилиты Boot-Repair

Если стандартные опции режима восстановления не помогли, можно воспользоваться мощной утилитой Boot-Repair.

**Установка и запуск Boot-Repair из режима восстановления:**

1.  В меню режима восстановления выберите "root" (командная строка).
2.  Попробуйте установить Boot-Repair. Если утилита не найдена в стандартных репозиториях, добавьте PPA (Personal Package Archive) для Boot-Repair:
    ```bash
    sudo add-apt-repository ppa:yannubuntu/boot-repair
    sudo apt update
    sudo apt install boot-repair
    ```
3.  После установки запустите утилиту командой `boot-repair`.
4.  Следуйте инструкциям на экране. Boot-Repair автоматически проанализирует вашу систему и предложит наиболее подходящее решение.

**Если меню GRUB недоступно:**

В этом случае вам понадобится загрузочная USB-флешка с Ubuntu. Создайте ее на другом компьютере, скачав образ Ubuntu с официального сайта и используя программу вроде Rufus (для Windows) или Startup Disk Creator (для Ubuntu).

1.  Загрузитесь с созданной Live USB.
2.  Откройте терминал.
3.  Выполните шаги по установке Boot-Repair, описанные выше (добавление PPA, обновление списка пакетов и установка).
4.  Запустите `boot-repair`.

Эта процедура позволит утилите получить доступ к вашей установленной системе Ubuntu и исправить загрузчик.

### Проверка системных журналов

Если ни один из предыдущих методов не помог, необходимо изучить системные журналы для поиска причин проблемы.

1.  В командной строке режима восстановления (root) выполните команду:
    ```bash
    journalctl -xb
    ```
    Эта команда отобразит подробные логи загрузки системы. Ищите сообщения об ошибках, которые могут указывать на конкретную проблему (например, с драйверами или пакетами).
2.  Также может быть полезна команда:
    ```bash
    sudo dmesg | tail -50
    ```
    Она покажет последние 50 системных сообщений, что часто помогает выявить сбои оборудования или драйверов.

### Проверка настроек UEFI/BIOS

Иногда проблемы с загрузкой могут быть вызваны настройками режима работы диска в UEFI/BIOS. Убедитесь, что установлен режим AHCI. Если вы устанавливаете Ubuntu совместно с Windows, установленной в другом режиме (например, RAID или Intel RST), могут возникнуть трудности, требующие дополнительных действий по восстановлению или переустановке Windows.

### Проверка установочного носителя

Если ошибка возникает непосредственно во время установки Ubuntu, проблема может быть в самой установочной USB-флешке или ISO-образе. Убедитесь, что вы используете последнюю версию программы для создания загрузочной флешки и что носитель исправен. Если вы используете утилиту Ventoy, попробуйте обновить ее до последней версии или откатиться на предыдущую, так как в некоторых версиях Ventoy были замечены ошибки, приводящие к проблемам при установке Ubuntu.
