Бесконечный перезапуск Docker-контейнера — типичная проблема при развертывании приложений. Контейнер запускается, приложение внутри падает, Docker перезапускает его по политике restart, и цикл повторяется. Причина почти всегда в логах —docker logs покажет, почему приложение завершается.

### Коды выхода и их значение

Код 0 — приложение завершилось штатно (норма для одноразовых задач). Код 1 — ошибка приложения (проверьте логи). Код 137 — OOM killer убил процесс (нехватка RAM). Код 139 — segmentation fault (ошибка в коде или повреждённые данные). Код 126/127 — нет прав на запуск или команда не найдена.

### Healthcheck и его влияние

Если healthcheck настроен и возвращает unhealthy, Docker не обязательно перезапускает контейнер (зависит от policy). Но если restart: unless-stopped или always — контейнер будет перезапускаться после падения. Временно отключите healthcheck, чтобы исключить его влияние на проблему.
