  - title: 1. Загрузка в режиме восстановления (Recovery Mode)
    body: >-
      При возникновении проблем после обновления, первое, что стоит попробовать
      — это загрузиться в режиме восстановления. Этот режим позволяет выполнить
      различные сервисные операции с системой, не загружая ее полностью.


      **Действие:**

      1. Перезагрузите компьютер.

      2. Во время загрузки (обычно при появлении логотипа производителя
      материнской платы или BIOS/UEFI) нажмите и удерживайте клавишу **Shift**
      (для систем с UEFI) или **Esc** (для систем с BIOS), чтобы вызвать меню
      загрузчика GRUB.

      3. В меню GRUB выберите пункт "Advanced options for Ubuntu"
      (Дополнительные параметры для Ubuntu).

      4. Выберите строку с ядром, которое вы хотите загрузить, и добавьте к ней
      слово "recovery" (например, `quiet splash -- recovery`). Если вы не видите
      такую строку, выберите вариант с "(recovery mode)" из списка.

      5. Нажмите Enter. Система должна загрузиться в меню восстановления.

  - title: 2. Восстановление пакетов и очистка системы
    body: >-
      В меню режима восстановления выберите опцию "dpkg" (Repair broken
      packages), чтобы попытаться исправить поврежденные пакеты. После этого
      можно попробовать очистить систему от ненужных файлов и пакетов.


      **Действие:**

      1. В меню режима восстановления выберите "dpkg" (Repair broken packages).

      2. Если этот пункт не помог, вернитесь в главное меню режима
      восстановления и выберите "root" (Drop to root shell prompt).

      3. Введите команду `apt update && apt upgrade -y` для обновления списка
      пакетов и установки доступных обновлений.

      4. Затем выполните команду `apt autoremove -y` для удаления устаревших и
      ненужных пакетов.

      5. Для очистки кэша пакетов введите `apt clean`.

      6. После выполнения команд введите `exit`, чтобы вернуться в меню режима
      восстановления.

      7. Выберите "resume" (Resume normal boot) для попытки загрузки системы в
      обычном режиме.

    body: >-
      Иногда проблемы возникают из-за некорректного обновления ядра. В этом

      **Действие:**

      1. Загрузитесь в режиме восстановления (см. Шаг 1).

      2. Выберите "root" (Drop to root shell prompt).

      3. Определите текущее установленное ядро. Для этого можно использовать
      команду `uname -r`.

      4. Чтобы переустановить текущее ядро, выполните команду, заменив
      `[версия_ядра]` на актуальную версию (например,
      `linux-image-5.15.0-56-generic`): `apt install --reinstall
      linux-image-[версия_ядра] linux-headers-[версия_ядра]`.

      5. Если вы хотите обновить ядро до последней доступной версии из
      репозиториев, выполните: `apt install --only-upgrade linux-image-generic

      6. После установки или переустановки ядра, обязательно обновите
      конфигурацию загрузчика GRUB: `update-grub`.

      7. Введите `exit`, чтобы вернуться в меню режима восстановления, и
      выберите "resume" для перезагрузки.
    command: >-
      apt install --reinstall linux-image-[версия_ядра]
      linux-headers-[версия_ядра] && update-grub

После установки обновлений операционная система Ubuntu может перестать загружаться или работать некорректно. Это может быть вызвано различными причинами, такими как конфликт пакетов, ошибки в ядре или повреждение системных файлов. К счастью, существует несколько способов восстановить работоспособность системы.

**Основные причины проблем после обновления:**
*   **Конфликты пакетов:** Новые версии программ могут конфликтовать со старыми или другими установленными компонентами.
*   **Ошибки ядра:** Обновление ядра Linux — критически важный процесс, и ошибки на этом этапе могут привести к невозможности загрузки системы.
*   **Повреждение файлов:** В редких случаях процесс обновления может привести к повреждению важных системных файлов.

Ниже представлены шаги, которые помогут устранить распространенные проблемы.

### 1. Загрузка в режиме восстановления (Recovery Mode)

Первым шагом при возникновении проблем с загрузкой является попытка войти в режим восстановления. Этот режим предоставляет доступ к инструментам для диагностики и исправления ошибок.

**Как войти в режим восстановления:**
1.  Перезагрузите компьютер.
2.  Во время начальной загрузки (когда появляется логотип производителя или информация BIOS/UEFI) нажмите и удерживайте клавишу **Shift** (для систем с UEFI) или **Esc** (для систем с BIOS), чтобы открыть меню загрузчика GRUB.
3.  В меню GRUB выберите пункт "Advanced options for Ubuntu" (Дополнительные параметры для Ubuntu).
4.  Найдите строку, соответствующую вашей версии Ubuntu, и выберите вариант с "(recovery mode)" или добавьте слово `recovery` к параметрам загрузки.
5.  Нажмите Enter. Система должна загрузить специальное меню восстановления.
