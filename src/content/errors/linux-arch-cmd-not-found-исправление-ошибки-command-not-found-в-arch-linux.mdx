Ошибка «command not found» в Arch Linux чаще всего означает, что оболочка Bash не может найти исполняемый файл, соответствующий введенному вами слову. Поскольку Arch Linux является минималистичным дистрибутивом, многие утилиты не установлены по умолчанию. Следуйте приведенным выше шагам для диагностики и исправления проблемы. Если команда не найдена даже после установки, проверьте наличие опечаток в названии или перезапустите терминал для обновления кэша путей.
