description: >-
  Пошаговое руководство по устранению ошибки «Приложение повреждено и его
  невозможно открыть» в операционной системе macOS, возникающей при запуске
  стороннего ПО.
symptoms:
  - Появление сообщения об ошибке при попытке запуска приложения
  - 'Система утверждает, что файл поврежден или не может быть открыт'
  - 'Приложение было скачано из интернета, а не из App Store'
causes:
  - >-
    Настройки безопасности macOS блокируют запуск приложений от неустановленных
    разработчиков
  - Повреждение атрибутов безопасности файла (quarantine)
steps:
  - title: Разрешение запуска приложений от любых разработчиков
    body: >-
      Откройте «Системные настройки» -> «Защита и безопасность». На вкладке
      «Основные» в разделе «Разрешать загрузку программ из:» выберите «App Store
      и от установленных разработчиков». Если приложение все равно не
      открывается, нажмите кнопку «Открыть все равно», которая появится в этом
      же разделе после неудачной попытки запуска.
    command: sudo spctl --master-disable
    image: null
  - title: Удаление атрибута карантина
    body: >-
      Если система по-прежнему считает файл поврежденным, необходимо
      принудительно снять с него «карантинный» флаг через Терминал. Замените
      путь к приложению в команде ниже на ваш.
    command: sudo xattr -rd com.apple.quarantine /Путь/к/вашему/приложению.app
    image: null
  - title: Переподпись приложения
    body: >-
      В крайнем случае, если атрибуты безопасности не помогают, можно
      переподписать приложение для текущей системы. Это сбросит старую цифровую
      подпись, которая может вызывать конфликт.
    command: codesign --force --deep --sign - /Путь/к/вашему/приложению.app
    image: null

Ошибка «Приложение повреждено» в macOS чаще всего связана не с реальной поломкой файла, а с политикой безопасности Apple, которая блокирует запуск программ, скачанных из интернета. Следуя приведенным выше шагам, вы сможете снять ограничения системы и запустить нужное ПО.
