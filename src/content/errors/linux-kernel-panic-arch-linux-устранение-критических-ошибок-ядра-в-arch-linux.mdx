Ошибки ядра в Arch Linux могут быть вызваны сбоями при обновлении или конфликтами драйверов (например, подсистемы DRM). Для решения проблемы необходимо воспользоваться режимом chroot с установочного носителя. Последовательно переустановите ядро, обновите образы initramfs и конфигурацию загрузчика. Если проблема сохраняется, проверьте логи загрузки через journalctl для выявления конкретного сбойного модуля.
