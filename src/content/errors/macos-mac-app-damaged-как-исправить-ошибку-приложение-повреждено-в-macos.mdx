symptoms:
  - >-
    При попытке запуска программы появляется сообщение «Приложение повреждено и

causes:
  - Система безопасности Gatekeeper блокирует запуск приложения
  - Приложение было скачано из стороннего источника и не имеет подписи Apple
  - Повреждение атрибутов расширенных свойств файла
steps:
  - title: Очистка атрибута карантина
    body: >-
      Часто macOS помечает скачанные файлы как потенциально опасные. Чтобы снять
      это ограничение, используйте терминал. Откройте «Терминал» (через поиск
      Spotlight), введите команду и перетащите проблемное приложение в окно
      терминала после пробела.
    command: sudo xattr -rd com.apple.quarantine
    image: null
  - title: Изменение настроек безопасности
    body: >-
      Убедитесь, что система разрешает установку приложений не только из App
      Store. Перейдите в «Системные настройки» > «Конфиденциальность и
      безопасность» и в разделе «Разрешить использование приложений, загруженных
      из:» выберите вариант «App Store и от подтвержденных разработчиков» или
      «Любые источники» (если доступно).
    command: spctl --master-disable
    image: null
  - title: Переподпись приложения (для продвинутых пользователей)
    body: >-
      Если предыдущие шаги не помогли, приложение может требовать принудительной
      переподписи для корректной работы с текущей версией macOS.
    command: codesign --force --deep --sign - /путь/к/приложению
    image: null

Ошибка «Приложение повреждено» на macOS чаще всего связана не с реальной поломкой файла, а со строгими настройками безопасности Apple (Gatekeeper). Система блокирует приложения, которые не были официально подписаны или загружены из App Store. Выполните шаги по порядку, чтобы разрешить запуск нужного вам ПО.
